# Glosario · Estadística para entender tests A/B

| Término | Definición | Lección |
|---|---|---|
| **Aleatorización** | Reparto de las unidades entre variantes por sorteo, para que solo la variante explique las diferencias sistemáticas. | 1.1 |
| **Error estándar** | Tamaño típico de la diferencia entre una estimación (una tasa, una media) y su valor real debida al muestreo. | [1.2](lecciones/1.2-variabilidad-por-que-dos-grupos-iguales-dan-tasas-distintas.md) |
| **Tasa de conversión** | Proporción de usuarios de un grupo que completan la acción medida. | 1.1 |
| **Test A/A** | Experimento con dos grupos que reciben lo mismo; mide cuánto difieren por azar. | [1.2](lecciones/1.2-variabilidad-por-que-dos-grupos-iguales-dan-tasas-distintas.md) |
| **Variabilidad muestral** | Variación de una estimación de una muestra a otra aunque la población no cambie. | [1.2](lecciones/1.2-variabilidad-por-que-dos-grupos-iguales-dan-tasas-distintas.md) |
